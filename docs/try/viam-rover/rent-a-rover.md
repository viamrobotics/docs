{{< alert title="Discontinued" color="caution" >}}
The Viam Rover rental program has been discontinued.
You can no longer reserve a rover through the Viam app.
If you already have a Viam Rover, see [Set up your own rover](/try/viam-rover/setup/).
To try Viam without hardware, see the [Quality Inspection tutorial](/try/quality-inspection/overview/), which uses a Gazebo simulation.
{{< /alert >}}

If you used the rover rental program in the past, any machine configurations from your rental sessions remain in your Viam account.
You can continue to use those configurations with your own hardware.
